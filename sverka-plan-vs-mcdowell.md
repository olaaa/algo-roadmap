(Cracking the Coding Interview, 6-е изд.) — RAG-источник
`rag/mcdowell-cracking-coding-interview.md`.

Блок — это блок из таблицы «Ядро паттернов (6 блоков)» в `algo-prep-plan.md`.
Задачи плана B (DP, сортировки, графы) в шесть блоков не входят — помечены как
«доп. (план B)».

## Как читать ссылки на книгу

RAG-файл — это сплошной markdown без разбивки на страницы, поэтому ссылки даны
по структуре книги: глава + номер задачи по нумерации 6-го издания + точная
фраза для поиска (Ctrl+F) внутри markdown. При OCR номера задач (вида «10.1»)
кое-где потерялись, так что ориентир для поиска — именно фраза-условие.

## Вывод

Книга хорошо закрывает блоки 1–2 (строки), 5–6 (поиск, деревья, графы) и
DP-задачи плана B (ступеньки, монеты, заливка). Дыры — лёгкие LeetCode-задачи
(Move Zeroes, Majority, House Robber, Symmetric Tree) и скользящее окно; они
закрываются опорными шаблонами из `algo-prep-plan.md`. Главное не пропустить:
корректность скобок (20) книгой не подстрахована.
