# Reverse Array (аналог 344. Reverse String)
*Разворот массива (дословно: развернуть массив; аналог задачи 344 Reverse String — разворот строки)*

**Сложность:** Easy · **Паттерн:** два указателя · **Класс:** `block01_arrays_twopointers.ReverseArray`

Базовое упражнение на паттерн «два указателя». Аналог LeetCode 344 (Reverse String), но для массива целых чисел.

## Условие

Дан массив целых чисел `nums`. Нужно **развернуть** его — переставить элементы в обратном порядке (первый становится последним и наоборот).

Сделать это требуется **на месте** (in-place), с `O(1)` дополнительной памяти: изменяем сам входной массив, а не возвращаем новый.

Что значит in-place / `O(1)` памяти: разрешено держать несколько скалярных переменных (индексы, одна временная переменная `temp` для обмена), но **нельзя** выделять новую структуру размером со вход — второй массив или список на `n` элементов. Объём вспомогательной памяти не должен расти с длиной массива.

## Примеры

### Пример 1

```
Вход:  nums = [1, 2, 3, 4, 5]
Выход: [5, 4, 3, 2, 1]
```

### Пример 2

```
Вход:  nums = [1, 2, 3, 4]
Выход: [4, 3, 2, 1]
```

### Пример 3

```
Вход:  nums = [42]
Выход: [42]
```

Массив из одного элемента разворачивать нечего.

## Ограничения

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- разворот выполняется in-place, дополнительная память `O(1)`

## Идея решения

Один указатель слева (`leftIndex`), другой справа (`rightIndex`). Меняем местами `nums[leftIndex]` и `nums[rightIndex]` через временную переменную `temp`, затем сдвигаем `leftIndex` вправо, `rightIndex` влево. Останавливаемся, когда указатели встретились в середине — к этому моменту все пары уже переставлены.

## Сложность

- **Время:** `O(n)` — по одному обмену на каждую пару (`n/2` обменов).
- **Память:** `O(1)` — разворачиваем без дополнительного массива.
