Неотсортированный массив, ищем пару элементов с суммой target. Индексы 0-based. Для каждого элемента считаем дополнение complement = target − nums[i] и проверяем, не встречалось ли оно раньше (LeetCode 1).

Как устроена HashMap
table — внутренняя таблица HashMap из 8 ячеек-бакетов (это не массив nums из задачи).
table[i] — бакет №i. Номер бакета для ключа — это остаток от деления hash на длину таблицы; длина у HashMap всегда положительная и степень двойки, поэтому остаток считают быстрым hash & 7 (для длины 8 — то же самое).
узел — это Node с полями key (число из nums) и value (его позиция i в nums). При коллизии узлы одного бакета связаны через поле next в цепочку (стрелка →).
