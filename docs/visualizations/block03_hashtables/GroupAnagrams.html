Group Anagrams — раскладывание по корзинам

Анаграммы неразличимы по составу букв, поэтому каждому слову считается «отпечаток» — ключ, одинаковый у всех анаграмм. Слова с одинаковым ключом попадают в одну корзину карты (LeetCode 49).
входной массив strs
шаг 0 / 0
карта groups — ключ и список слов с этим ключом
На что смотреть
Ключ — это и есть вся задача. Идея хеш-таблицы тут очевидна; сложность Medium берётся из того, что ключ надо придумать самому, а не получить готовым из условия.
computeIfAbsent делает три вещи разом. Находит список по ключу, создаёт его при отсутствии, возвращает для добавления слова. Функция вызывается только тогда, когда ключа не было — лишних списков не создаётся.
Разделитель в векторе частот обязателен. Переключи способ на «вектор частот»: между счётчиками стоит #. Без него слово с одной a и одиннадцатью b дало бы ключ 111… — и слово с одиннадцатью a и одной b тоже. Разные слова слились бы в одну группу.
