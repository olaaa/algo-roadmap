Valid Anagram — один массив счётчиков на две строки

Буква из s увеличивает счётчик, буква из t уменьшает его. Если строки анаграммы, все увеличения компенсируются уменьшениями и массив обнуляется (LeetCode 242).

На что смотреть
Проверка длин идёт первой. Она дешёвая и заодно делает возможным единый проход сразу по двум строкам одним индексом.
Знак счётчика говорит, где перекос. Положительный — буква лишняя в s, отрицательный — лишняя в t.
Ответ виден только после цикла. Внутри цикла нарушений не бывает в принципе: он лишь копит счётчики и ничего не сравнивает. Поэтому финальная проверка — обнулился ли весь массив.
