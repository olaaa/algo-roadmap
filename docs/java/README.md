# Язык Java

Справочники по механике самого языка — то, что спрашивают на собеседовании вместе с алгоритмом, но что не является ни задачей, ни структурой данных.

Границы папок:

- `docs/problems/` — разбор конкретных задач;
- `docs/datastructures/` — типы стандартной библиотеки: `Queue`, `Deque`, `Stack`, `String`;
- `docs/java/` — устройство языка и JVM: переменные, память, приведение типов, равенство объектов.

Утверждения проверяются запуском на локальной JDK 25: байткод через `javap -c`, ошибки — фактическим выводом `javac`. Иллюстрации — отдельными файлами `.svg` в `img/`.
