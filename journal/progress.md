### Рецепт визуализаций (ВАЖНО — воспроизвести в новом чате)
  Формат: один самодостаточный HTML-файл  (имя <Класс>.viz.html),
  чистый HTML+CSS+JS, БЕЗ библиотек (p5.js не нужен), открывается в браузере без установки.
  Составляющие, которые понравились и надо сохранять как стиль:
    * массив рисуется <div>-ячейками, у каждой ячейки индекс снизу;
    * указатели (L/R или i/j) подписаны над/под ячейками, двигаются по шагам,
      отсечённая/пройденная часть тускнеет (класс dim), совпадение — зелёная подсветка (hit);
    * массив шагов steps[] строится заранее из логики алгоритма, каждый шаг = {состояние, line, msg};
    * статус-строка объясняет каждый шаг словами по-русски
      (напр. "sum = 2 + 15 = 17 > target → сдвигаем r влево");
    * справа блок кода с подсветкой активной строки (соответствие через поле line);
    * управление: кнопки Назад/Вперёд, стрелки ← →, авто-проигрыв (пробел), Сброс,
      поля ввода массива и target + кнопка "Построить" для пересборки;
    * тёмная тема, моноширинный шрифт для чисел/кода.
  Как пользователь будет просить: "сделай визуализацию как для twosum, но для <Класс>".
