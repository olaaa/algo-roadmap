      отсечённая/пройденная часть тускнеет (класс dim), совпадение — зелёная подсветка (hit);
    * массив шагов steps[] строится заранее из логики алгоритма, каждый шаг = {состояние, line, msg};

    * управление: кнопки Назад/Вперёд, стрелки ← →, авто-проигрыв (пробел), Сброс,
      поля ввода массива и target + кнопка "Построить" для пересборки;
